# Week 12 Journal: Final Presentations & Critique
My biggest learning this semester is that anything is possible to code when you lead with imagination and creativity. At the start, I wasn't sure if I could successfully mix the aesthetics of Tron and 80s Synthwave, but the process showed me that a unique vision provides the best roadmap.

* **Overcoming Challenges:** While the technical parts like creating the manual square grid or stabilizing the moon's rotation—were challenging, I learned that spending dedicated time with the code is the only way to "figure it out."

* **Creative Fusion:** Successfully blending the cyan wireframes with rolling Perlin noise mountains taught me that generative design is a powerful tool for self-expression, not just a math exercise.

## How do you see generative design in your future practice?
Since my goal is to become a game developer, I see generative design as an essential part of my future toolkit.

* **Procedural Content:** The concepts I used in this project, such as using Perlin Noise for terrain or the modulo operator (%) for infinite movement, are the foundations of procedural generation in game engines like Unity.

* **Efficient Design:** Learning to create complex environments using math rather than manual 3D modeling will help me build larger, more dynamic game worlds that are light on memory but heavy on style.

* **Next Steps:** Next Steps: I plan to take these generative logic skills and apply them to my future projects, moving from P5.js into C# and more advanced game development environments.
